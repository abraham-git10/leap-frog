### Controls

| Key | Action |
| :--- | :--- |
| **`W`** | Move Up |
| **`A`** | Move Left |
| **`S`** | Move Down |
| **`D`** | Move Right |
| **`N`** | Reset Game / Start New Game |

### Game Rules & Objective

1. **Cross the Road**: Navigate across 5 traffic lanes without getting hit by a vehicle.
2. **Cross the River**: Jump across 3 log lanes and 2 turtle lanes. Staying on top of moving logs and turtles keeps you afloat; stepping into open water results in losing a life.
3. **Reach the Lily Pads**: Land on all 4 lily pads at the top edge of the board to win the game.
4. **Lives & Timer**:
   * You start with 3 lives.
   * You have 30 seconds to reach the lily pad. Running out of time costs 1 life.
